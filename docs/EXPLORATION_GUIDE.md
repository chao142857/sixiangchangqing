# 《思想常青》自由探索与课堂导览

## 自由探索（默认）

打开“离线演示/离线阅读.html”，不要移动或删除旁边的 `assets/` 文件夹。推荐 Chrome。进入后可以直接点击桌上的书、档案、地图；不需要先启动自动播放。

三章各有四组双页内容，覆盖现有原典标题与短句、历史介绍、思想概念、完整案例摘要、现实启示、追问及课堂口播。书页引用链接以来源编号保留，原典全文仍需从相应来源网站阅读，网页画面不是原件影像。

- “上一页 / 下一页”：翻阅全部内容。
- “关闭文献”：文献回到原位，不会直接跳到下一场景。
- “上一场景 / 下一场景”：依次探索历史、当代场景，可向后返回。
- “目录”：直接选择三章，或打开独立的“参考文献与制作说明”。
- 手机书页可正常滚动；翻页控制保留在阅读层底部。

## 自动导览（可选）

点击“自动导览”，观看约 2 分 04 秒的序幕、三章与终章。导览与手动阅读使用同一份正文，不会隐藏正文或翻页控件。可以暂停、跳过本章或退出。

导览中点击文献正文、翻页或主动打开桌面物件，会暂停自动进度并交给用户阅读。关闭文献后，导览继续保持暂停；用户可选“继续导览”或“退出导览”。继续导览时先自然收起当前文献，再衔接该章当代场景，不会从某一密集文字页强行接续计时。

## 资料与制作说明

正常场景只保留一个标题。素材性质、图像来源、年代核验、地图/卫星示意边界集中在“目录 → 参考文献与制作说明”，亦见本包中的 `文献来源.md`、`美术与来源.md`。这些画面不是历史照片或实物扫描，书页不伪造人物对白。

本包轻量图片经 WebP/JPEG 压缩，不改变内容与交互；不含视频、源码依赖或课程教材 PDF。外部原典链接需要联网。
