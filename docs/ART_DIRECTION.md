# 三章 CG：美术与来源

## 本轮更新（当前版本）

- 寻乌 `room-clean.png` 是在 `workroom.png` 基础上使用 OpenAI 图像编辑逐步移除线装书与笔筒、并补画桌面和墙面的 clean plate；未经编辑的原图仍保留。`room-interior.png` 从该底图去掉窗外区域；独立生成并向四周扩展的 `exterior-extended.png` 被放在窗洞后方，不再重复叠放完整底图。
- `book-closed.png`、`brush-isolated.png` 是从原 CG 按轮廓提取的透明物件；`book-shadow.png` 是原图与补画底图的亮度差生成的独立接触阴影。打开的 `book-open-cutout.png` 是生成的空白书页图按纸张轮廓去掉背景，非扫描原件；`atlas-cutout.png` 是绘制山水的生成式过渡插画。提取脚本为 `scripts/make-cg-layers.mjs`；它只负责抠图与差分，**不负责底图补画**。
- 延安、遵义已分别接入艺术重建工作场景、交互文献和当代意象；两场景均用图像编辑移除原有互动纸张后补画桌面，再叠加独立的透明纸张。延安原始生成图中疑似照片的墙面小图已在实际使用的底图中移除。北斗画面是通用卫星概念，不代表真实卫星型号或轨道。浦江室内图不是具体接访现场。
- 历史→当代转场中纸上连接线是**方法联系示意**，不是实际行进路线或地理地图；“1930/2003”等年份来自原有资料。场景与文本均使用本地资产及原有内容数据。
- 当前原图约 1672×941，1080p 投影会放大；抠图边缘、阴影及不同屏幕的运动边界仍需人工逐帧审美验收。延安、遵义目前是补画底图＋独立物件，尚无寻乌那样独立可移动的远景与前景，不能宣称三章均已达到专业完整多平面分层。任何真实照片或原件仍需另行取得授权。

## 叙事边界

画面是以1930年代赣南客家工作空间为灵感的**生成式艺术重建**，不是寻乌旧址实景、实物原件、历史照片或空间测绘复原。浙江画面是乡村意象，不指代任何具体村庄或工程成果。纸张上的文字是现代排印；没有生成历史人物、对白、签名或手稿。所有情景仅服务于视觉叙事，不作为事实证据。

画面中“没有调查，没有发言权”是《反对本本主义》第一节标题的节录，见 [H1](https://www.12371.cn/2012/08/10/ARTI1344592797863461.shtml)。寻乌调查及著作关联见[寻乌县政府纪念馆简介 H5](https://www.xunwu.gov.cn/xwxxxgk/xwzd107/202506/fb44eb6646584b47bf28849d10780f51.shtml)；千万工程事实见 [S7](https://www.zjzzgz.gov.cn/art/2023/6/2/art_1476676_58891564.html)。历史与当代之间的思想联系是本组分析，并非因果证明。完整史料与核验边界仍见 `SOURCES.md`、`SOURCE_AUDIT.md` 和 `src/data/`。

## 上一轮的缺口与后续可完善资产

上一轮的前后景直接从扁平图裁切、没有补画，曾存在重复像素与残留册子；寻乌已按本页“本轮更新”替换。下列更高规格的美术交付仍可用于后续精修，不应被误认为已全部完成。

交给画师或图像后期时需要：

1. `room-clean.webp`：至少 2560×1440、四周 8–10% 安全留边的干净中景；移除笔筒、互动册与窗外，补画桌面、墙壁和窗沿。
2. `window-exterior.png`：同机位窗外远景透明层，窗框遮挡范围外额外补画；不得把建筑细节称为旧址实况。
3. `foreground-brush.png`：笔筒、毛笔及桌角的透明 PNG，含完整边缘、底部遮挡和阴影；留足镜头位移余量。
4. `document-closed.png`、`document-open.png`：同光向、同尺度的透明文献道具，书册下方独立接触阴影；封面无伪造字迹，打开页留排字安全区。配套无文献桌面补画。
5. `light-dust.png` 或独立光束序列：透明、低对比度，可循环；注意课堂投影不遮挡原典文字。
6. `zhejiang-clean.webp` 及独立前景叶片、远山层：同样 2560×1440 起、保留安全边缘；若换成真实当代照片，另附摄影者、授权、地点与拍摄日期，不能伪称本图是具体工程现场。
7. 如需真实原件扫描或寻乌历史照片，须从档案机构取得可展示及复制授权，附档案号、年代、来源与授权证明；现有生成图不能替代这些证据。

建议交付分层 PSD/ORA 及无损透明 PNG，另提供压缩 WebP/AVIF（分别检查浏览器兼容性）；图层保持相同画布、色彩空间及锚点，切分后逐像素检查边缘。画面和独立图层应有足够延伸，才能扩大视差而不露底。
