# 《薪火相传 · 思想常青》终章验收

## 内容与操作

- 全片约138秒；114秒进入终章，终章独立时间线约23.5秒。第一段为三个历史场景蒙太奇，第二段为浙江千万工程、浦江经验与北斗，最后进入红金档案长卷并定格。
