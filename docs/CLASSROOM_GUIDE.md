# 《思想常青》课堂导览

## 使用方法

启动项目后打开 `http://localhost:5173/`，点击“全片导览”。全片约 2 分 04 秒，包含序幕、三章、终章；可以暂停、继续、跳过或用“章节”跳转。按 H 隐藏/恢复界面。每章也可单独自动播放约 34 秒。手动点击桌上文献可完整阅读；“资料模式”保留原典、案例、来源和本组分析。

离线演示：保持 `离线阅读.html` 与旁边的 `assets/` 文件夹在一起，使用 Chrome 打开；原典外链需要联网。应在投影电脑上提前演练。

| 1:20–1:54 | 遵义与北斗 | 遵义会议与独立自主解决中国革命实际问题的探索相关。北斗案例提醒我们，积累自主能力与兼容共用、开放合作可以并行。 |
| 1:54–2:04 | 终章 | 本组认为，这些思想方法仍有启示，但必须结合新的制度、技术和社会条件，在实践中检验。 |

上述当代联系是本组方法论分析，不证明复杂成果由某一思想单独造成。完整案例和教师追问见 `CASE_MATERIALS.md`；出处和核验状态见 `SOURCES.md`、`SOURCE_AUDIT.md`。
