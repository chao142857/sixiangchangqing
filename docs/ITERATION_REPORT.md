## 限制

- 录像为无头 Chrome 的真实页面录制，不是实地投影设备录像；未测普通笔记本帧率、真实投影颜色或各移动浏览器兼容性。
- 寻乌使用生成式 clean plate 与可分离的远景、前景、文献和接触阴影，原始尺寸约 1672×941，1080p 为放大展示；纸张交接不是对真实物理开页的模拟。
- 延安和遵义的背景目前仍是平面 clean plate 加独立交互物件，没有独立的远景/前景补画；正式多平面资产、边缘精修和更高分辨率仍待画师制作。生成画面不构成历史照片，详见 `ART_DIRECTION.md`。
- 原有三案数据与文献保留，没有将本组分析包装成历史事实或人物对白。单次自动播放只播放当前所选章节，需要通过“章节”手动切换其他章。
