## 已完成与测试

- 安全基线：Git 提交 `f6e8567` 保留上一轮三章代码、CG、寻乌交互及史料。
- `npm run build`、`npm run typecheck`、`npm run lint` 通过；构建包含原有三案与来源核验。
- `npm run test:cinematic`：本机 Chrome 无头浏览器，1920×1080 与 390×844，检查三章场景、文献/档案/地图、三案、资料模式、双击、暂停、跳过、章节跳转、返回、移动阅读及页面错误。

## 仍需人工验收或补充

- 三章使用艺术重建，不是历史照片、特定旧址原貌或文献扫描；没有虚构人物对白。遵义地图和北斗轨道是概念意象，非实际行军路线、真实卫星型号或轨道参数。原典、史料与当代案例以 `SOURCES.md` 和 `src/data/` 为准。
- 图像源分辨率约 1672×941，1080p 投影会放大；独立图层虽有图像编辑补画，但门窗接缝、抠图细部、阴影和卫星差分边缘仍需专业画师逐帧检查。详见 `ART_DIRECTION.md`。
- 如需历史原件、现场照片、测绘建筑或真实地图，仍需档案来源和展示授权；不能以生成图代替。真实投影设备、普通笔记本帧率及更多移动浏览器尚未实测。
- 早期 `docs/ITERATION_REPORT.md` 与旧汇报 ZIP 记录上一轮，不代表全片当前状态。
