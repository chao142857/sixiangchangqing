## 电影式叙事（当前入口）

终章《薪火相传 · 思想常青》的操作、录制文件和接管验收见 [终章报告](docs/FINALE_REPORT.md)。

当前入口包括寻乌→千万工程、延安→浦江经验、遵义→北斗三个章节。`npm run dev -- --port 5173` 后访问 `http://localhost:5173/`。默认自由探索：点击桌面书、档案、地图进入四组双页阅读，用“上一页 / 下一页”翻阅或“关闭文献”回到场景；“上一场景 / 下一场景”切换历史与当代。“目录”可直达章节及独立的“参考文献与制作说明”。点击“自动导览”可观看约2分18秒全片；北斗画面亦可手动点击“进入终章”。导览中点击正文或翻页会暂停并交给用户阅读，关闭后可选择继续或退出导览。所有正文与播放状态无关，引用来源仍可查阅。`Esc` 收起文献或说明页。`npm run build` 构建，`npm run test:cinematic` 运行三章阅读回归测试。

新 CG 是生成式艺术重建，不是历史照片；图层和剩余资产见 `docs/ART_DIRECTION.md`，本轮阅读恢复验收见 `docs/EXPLORATION_REPORT.md`。离线版需要 `dist/离线阅读.html` 和其旁边的 `assets/` 文件夹。阅读恢复前安全提交为 `65370a7`；更早的工作快照位于 `backups/cinematic-before-art-iteration.tar.gz`。下方说明记录的是**重构前旧版**的功能与状态，其中三维、旧版阅读入口、时长和离线功能描述不适用于当前默认入口。

```bash

npm ci

```

打开终端打印的 Local 地址，默认 `http://localhost:5173/`。已经安装依赖时直接运行 `npm run dev`。同一局域网的手机可使用终端中的 Network 地址访问，电脑需要保持服务运行。Ctrl+C 停止。

## 展览与操作

- 序章“思想常青”：历史书桌、真实档案照片与文献，从“走进历史”进入。
- 实事求是：1930年寻乌调查与《反对本本主义》，转向浙江千万工程。
- 群众路线：延安时期与1943年领导方法文献，转向浦江经验。
- 独立自主：1935年遵义会议与历史地图，转向北斗系统。
- 终章“思想何以常青”：三个方法的现实意义；讨论题、史料与长文在可选阅读层查看。

课堂预设导览为150秒（12＋42＋42＋42＋12秒），每个思想章节的历史与当代部分各21秒。支持暂停、继续、上一场景、下一场景、案例跳转和退出。自由探索用于查看展品。按 H 隐藏/恢复全部UI，隐藏后也可点击右下角恢复区域；菜单可选流畅模式或阅读模式。全屏由用户点击按钮触发，浏览器可能要求手势授权。三维是原创艺术示意，不是历史空间、具体村庄或真实轨道复原。

低性能设备或WebGL不可用时使用无三维阅读模式，也可直接打开 `http://localhost:5173/?view=reading`，该入口不会创建三维画布。移动端保留文字与文献，三维画质可以降低。减少动画的系统设置会影响镜头运动。默认静音，无外部音频。

## 内容修改与交接文件

- `src/data/content.json`：案例事实、理论解释、现实启示、口播、讨论反馈、结论、文献与核验状态。
- `src/data/scene-history.json`：寻乌、延安、遵义三地史实、原典节录与建筑参考边界。
- `src/data/history-exhibits.json`：保留四个历史文献节点，明确原作时间和引用网页。
- 场景与导览配置：查看 `src/data/` 中展览配置文件；渲染组件与内容分离。
- `CASE_MATERIALS.md`：PPT组可直接用的三案摘要、理论联系、现实启示、口播及出处。
- `PRESENTATION_GUIDE.md`：约2分半讲解路线、每幕口播、PPT交接与老师追问。
- `SOURCES.md`：历史和当代文献、图像模型字体的来源与使用边界。
- `SOURCE_AUDIT.md`：逐项事实核验记录。
- `THIRD_PARTY.md`：研究与采用的开源项目、许可证和资产边界。

修改内容后执行 `npm run materials`，再构建。CASE_MATERIALS由数据自动生成，优先编辑数据而不是生成文件。

## 当前视觉实现的边界

主场景是有实际厚度、门窗、楼层、瓦顶和室内道具的程序化三维建筑，采用原创表面纹理与真实档案影像；没有使用测绘模型或照片级历史建筑GLB。寻乌、延安和遵义场景为依据文献的风格化艺术重建。书桌上的文献是现代排印陈列，地球与卫星场景是示意性表达。遵义背景采用文字史料陈列，目前未加入原始历史地图扫描件。照片与原典出处可以查证，道具、布局和镜头并不构成真实历史现场证据。
